/01

Real Estate Lead Qualification Agent

/02

A Telegram agent that holds a real conversation with property leads — greeting them, qualifying them on type, budget and area, showing matching listings, sending photos when asked, and booking site visits. It speaks English, Hindi, Kannada, Tamil and Konkani, and holds whichever language the lead opens in.

The problem it solved
  • Enquiries arrive at night and on weekends when no one is available to answer.
  • Sales staff spend hours qualifying leads who were never going to buy.
  • Leads across five languages get inconsistent answers depending on who replies.
  • Site visits and lead details live in WhatsApp threads with no reliable record.
How it is built
  • Deterministic Python owns every decision — which properties match, what stage the conversation is in, whether a booking is real. The model only reads intent and words the reply, so it can never invent a property or a price.
  • Photos are sent one at a time with consent, not dumped in a batch. A listing with no photos says so and offers a site visit instead.
  • Every conversation asks who is speaking before anything is recorded against a lead, so a forwarded link never attributes one person's booking to another.
  • 132 tests, several of them regressions from bugs that only surfaced in real conversations.
Tech stack
  • Python
  • FastAPI
  • Anthropic Claude API
  • Telegram Bot API
  • Supabase
  • PostgreSQL
  • Google Sheets API
  • pytest
